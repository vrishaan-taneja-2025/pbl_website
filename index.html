CropCare

AI-powered crop disease detection using deep learning and hybrid architectures.

Problem Statement

Crop diseases significantly impact agricultural productivity. Manual diagnosis is slow, inaccurate and requires expertise.

Solution

CropCare uses AI to automatically detect diseases and provide actionable recommendations.

Methodology

Dataset

PlantVillage dataset with 38 classes.

Model

MobileNetV2 is used for deployment. Additionally, a custom CNN-Transformer hybrid model was developed achieving 97% accuracy.

Tech Stack

FastAPI, PostgreSQL, TensorFlow, Docker.

Results

Accuracy 97%
Loss 0.092
F1 Score 0.97

Hybrid CNN-Transformer model achieved strong performance across all 38 classes. MobileNetV2 ensures fast real-time inference.
